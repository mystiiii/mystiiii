### About Me
Hey! I like building things that make life easier for everyone (mostly me).

During a Tech Summit workshop, I heard a speaker say, *"Ang mga data engineers ay tamad"* ("Data engineers are lazy")—and I've never agreed with anything more. As a student aiming for data-related roles, I'll happily spend two hours automating a task just to save ten seconds later. Work smart, not harder. 🤷

Right now, I'm diving into DevOps, Docker, and Kubernetes so my pipelines and projects can build, deploy, and babysit themselves.
